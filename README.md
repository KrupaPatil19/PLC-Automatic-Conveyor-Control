# PLC-Based Automatic Conveyor Control System

## 📌 Project Overview

This project demonstrates a PLC-based automatic conveyor control system using the **Mitsubishi FX5U PLC** and **MELSOFT GX Works3** software. The system uses Ladder Diagram programming to control conveyor operations, count objects, reset the counter, and indicate when a predefined object count is reached.

## 🎯 Aim

To design and develop a PLC-based conveyor control system that performs start/stop operations, object counting, counter resetting, and count-completion indication using Ladder Diagram programming.

## ⚙️ Technologies Used

- **PLC:** Mitsubishi FX5U
- **Programming Software:** MELSOFT GX Works3
- **Programming Language:** Ladder Diagram (LD)
- **Control Method:** PLC-based automation

## 🔍 Working Principle

The system operates according to the following sequence:

1. **Start:** Activates the conveyor run command.
2. **Stop:** Stops the conveyor operation.
3. **Object Detection:** Generates input signals when objects are detected.
4. **Object Counting:** A PLC counter tracks the detected objects.
5. **Count Completion:** An indicator turns ON when the preset count is reached.
6. **Reset:** Clears the counter for a new counting cycle.

## 🧠 Key Concepts

- Programmable Logic Controller (PLC)
- Ladder Diagram programming
- Digital inputs and outputs
- Internal relays and latching logic
